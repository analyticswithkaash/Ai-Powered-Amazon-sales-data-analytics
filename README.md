
# AI-Powered Amazon Product Analytics & Rating Prediction

An end-to-end data analytics and machine learning project analyzing 1,348 Amazon products using Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Seaborn.

The project covers data cleaning, exploratory data analysis (EDA), K-Means and Hierarchical Clustering, discount–rating correlation analysis, customer review sentiment analysis, anomaly detection, and product rating prediction using Random Forest Regression.

**Key Highlights:**
- Analyzed 1,348 Amazon product records.
- Identified 5 product segments using K-Means Clustering.
- Analyzed relationships between discounts and customer ratings.
- Detected anomalies, outliers, and sentiment–rating mismatches.
- Trained and evaluated regression models using MAE, RMSE, R², and cross-validation.
